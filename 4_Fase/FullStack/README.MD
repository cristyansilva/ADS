# Formulário com Regex

Projeto desenvolvido em **HTML** para praticar o uso de **Expressões Regulares (Regex)** na validação de campos de um formulário.

## 📋 Sobre o projeto

O formulário solicita diferentes tipos de informações e utiliza o atributo `pattern` do HTML para verificar se os dados seguem formatos específicos.

Entre os campos validados estão:

* Nome completo
* CPF
* Matrícula
* E-mail
* E-mail institucional da FMP
* Telefone
* Data de nascimento
* RG
* CNPJ
* Número do cartão
* Validade e CVV
* Inscrição Estadual
* Endereço
* CEP
* Tipo sanguíneo
* Lote
* Latitude e longitude
* Código de barras EAN-13
* Placa Mercosul

## 🛠️ Tecnologias

* HTML5
* Expressões Regulares (Regex)

## 🎯 Objetivo

Praticar a criação e aplicação de **Regex** para validar diferentes formatos de dados diretamente em um formulário HTML, utilizando recursos como `pattern`, `required` e `title`.

## ▶️ Como executar

Basta abrir o arquivo `.html` em qualquer navegador.

Não é necessário instalar nenhuma dependência ou servidor para executar o projeto.
